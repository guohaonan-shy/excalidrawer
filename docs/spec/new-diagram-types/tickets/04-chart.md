# 04 — 柱状 / 折线：axis 向上、chart 入口 skill

**Blocked by**：01 — 登记三个新入口 skill 的名字
**设计冻结**：不涉及 UI

## 要建什么

用户说「画个季度营收柱状图」或「画个 DAU 折线」，都由一个 `chart` 入口 skill 接住，画出手绘风的简单类别对比或趋势图。现在画不对：axis 竖着只能向下长（0 在上、100 在下），柱子从顶上倒挂；把 `domain` 倒过来写（首大于尾）会直接报错。

两样东西：

1. **axis 向上**：axis 的方向参数在现有的 `"x"`（向右）、`"y"`（向下）之外加 `"up"`：从起点往上长，mark、tick 和换算跟着反过来，换算仍是「起点 + (数值 − 下限) × 每单位像素」，只是每单位像素为负。`domain` 仍然只许首小于等于尾。`"x"`、`"y"` 的现有行为一点不变，时间线不受影响。axis 的参考里「图表坐标轴」一节改用 `"up"`，`compute_layout` 工具定义里 axis 那一行说明写上新方向。
2. **`chart` 入口 skill**：按步骤 skill「新增一种图类型」的清单写，构图分柱状、折线两节：
   - 柱状：类别沿横轴，柱子从 0 往上长，柱顶写数值。类别名平均超过 8 个字符或超过 8 个类别时横过来：类别沿竖轴往下排、柱子向右长。最多 3 个系列，多系列时同一类别的柱子并排、配 legend。
   - 折线：时间沿横轴，数值轴从一个整齐的 tick 起（不强求从 0），每个数据点一个小圆点、点之间连线，最后一个点旁写数值。最多 3 条线，配 legend。
   - 共用：数值轴的 tick 用 axis 的刻度，tick 处画浅灰虚线网格，轴标题可选。柱子、折线、网格线用 axis 的换算画，不加图表组件。只做简单的类别对比和趋势：不做双轴、堆叠、饼图。
   - 澄清问题：内容（类别或时间点、每个系列的数）说全了不问；柱状还是折线按数据是类别还是时间推，两种都说得通才问；单位和轴标题用户没说就问。

和别的工单共享的文件、怎么避免冲突：布局模块里只改 axis 函数内部，`compute_layout` 的工具定义里只改 axis 那一行说明；工单 03 同时在这两个文件末尾加新组件，不要碰末尾。

示例：一个新的 chart figures 模块出柱状、折线各一张，README 图库脚本只加它的导入和一次调用，README *What it makes* 加两格。
