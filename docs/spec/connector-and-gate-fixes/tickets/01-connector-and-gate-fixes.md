# 01 — 箭头标签按实际字宽定框，绕行 clearance 与 Layer B 孤词写进步骤 skill

**Blocked by**：无——可立即开工
**设计冻结**：不涉及 UI

## 要建什么

三件小事，一起落在 `release/0.6.0` 上：

1. **箭头标签框宽**：sugar 里给箭头 / 线写 `text` 时，标签是一个单独摆放的文字元素，框宽现在按「字符数 × 9，最少 28」估，中文一个字实际约等于字号（14 号就是 14px），所以中文标签框总比字窄。改成跟节点文字、flowchart 模板边标签、Layer A 的文字溢出检查同一把尺（仓库里按字符类型和字号估宽的那个函数），多行（按 `\n` 分）取最宽一行，保留最少 28 的下限；字号 14、框高 18 不变。按 id 连的（L1–L3）和自己给 points 的（L4）走同一处，都要生效。改完后：「失败重跑」这类中文标签不再报 TEXT_OVERFLOW_X；竖直线段旁的中文标签（框贴线摆在一侧、文字在框里居中）不再越过线；英文标签框宽基本不变。
2. **绕行 clearance 的量法**：步骤 skill 的连线参考里「长距离绕行：`via`」一节，示例下面补一段说明——`clearance` 从两个连接点里更靠绕行方向的那一个量起（`via: "below"` 就是更低的那个），连接点是 `fromSide` / `toSide` 定的边上的点、不是框的外沿；默认 60；只看两端、不看沿途别的框，沿途有更突出的框要把它超出的距离加上；建议出入边写成跟 `via` 同一侧，这时 `clearance` 就是线离框底（或顶 / 侧）的距离。配一个带数字的例子：同排三个框顶边 y=40，两端高 60（连接点 y=100），中间框高 140（框底 y=180），`clearance: 50` 时绕行横线在 y=150、从中间框穿过；要留 30 的空隙就得填 110。同一参考里 `routeU` helper 那一行说明（现在写「`clearance` 是离开多远」）改成同一语义或指向这一段。
3. **Layer B 孤词**：步骤 skill「出图」→ 两层质量关 → Layer B 的第 1 条（Labels）补上：标签折行后最后一行只剩一个词也算 FAIL，修法是缩短这句或自己在合适处用 `\n` 换行让几行长度接近。并进第 1 条，不新增第 6 条（正文写着「all five PASS」）。

另外：CHANGELOG 只在 Unreleased 下记这三条（标签框宽记 Fixed；两处文档记在合适的分节），不写版本号。

## 验收标准

- [ ] 横排两框、按 id 连箭头、`text: "失败重跑"`：desugar 后标签框宽 ≥ 56，`validate` 不报 TEXT_OVERFLOW_X（新测试，先红后绿）
- [ ] 竖排两框、按 id 连箭头、`text: "失败后重新排队"`：标签框整个在线的一侧，框宽 ≥ 文字估宽（98），所以居中的文字不越过线（新测试）
- [ ] 英文标签 `"Retry fail"`：不报警，框宽等于文字估宽与 28 取大（回归测试）
- [ ] L4（自己给 points）的箭头带中文 `text` 也按实际字宽定框（新测试或同一测试覆盖）
- [ ] 照新写的 clearance 说明算上面「中间框高 140」那个例子，填 110 渲染后 Layer A 干净；填 50 报 ARROW_CROSSES_SHAPE（手工核，结果写进 PR 描述）
