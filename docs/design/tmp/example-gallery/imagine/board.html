这一轮比的是语言：底色、字体、形状、语气。每个变种上半是样张（色板、字体、形状、语气），下半是一块能点的图库片段（tab 能切、Input 能展开、图点开是原尺寸 PNG），图全是引擎真画的。

真正分开它们的是两件事：白图和底色什么关系（贴在纸上 / 化进白页 / 暗处唯一亮的东西），手写体铺到哪（只到名字 / 所有人话 / 连链接都手写）。A、B、C 是同一族（暖纸 + 红色 accent + 手写配等宽），差在处理，不是三个方向。
