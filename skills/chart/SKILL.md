# excalidrawer chart

图表讲数字之间的大小和走向：柱状图比几个类别谁大谁小，折线图看一个量随时间涨还是跌。读者应该一眼看出最大的、最小的、变化的方向，数值再靠柱顶或末点旁边的数字读准。这里只做简单的类别对比和趋势，不是通用图表工具。下面四步走：问清楚、构图、出图、对照常见画坏法检查。

## 1. 问清楚

用户的描述已经能列全这张图的全部内容（类别或时间点，以及每个系列在每一格上的数）就不问，也不去读提问规则；柱状还是折线，数据是类别还是时间一般能直接推出来。只有单位和轴标题没说，或者柱状还是折线真的两种都说得通时，才要问。否则先看提问的通用规则：调 skill `steps`（Claude Code 用 Skill 工具调 `excalidrawer:steps`；其他宿主读 `../steps/SKILL.md`），看它的『clarify』。这一步只读这一节。

要问的事：

1. **内容**：自由文本。类别或时间点有哪些，每个系列在每一格上的数是多少。用户给的是一张表、一段 CSV 或一段代码里的数组时，直接从里面读，不再问。
2. **柱状还是折线**：数据是类别（渠道、城市、季度之间比大小）就是柱状，数据是时间（按月、按周的变化）就是折线，这样推，不问。两种都说得通才问，单选，把推荐项放第一位：同样是按季度的营收，用户要比各个季度谁高，用柱状；要看增长的走势，用折线。
3. **单位和轴标题**：用户没说就问。数值的单位是什么（美元、百万、百分比、千人），要不要给轴写标题。单位写进数值轴的标题。

超过三个系列时，不要硬塞进一张图：问用户留哪三个，或者拆成两张。

导出格式不用先问：对话里读得出图要去哪就直接定，读不出来才在出图时问一句（规则在 `steps` 的『出图』里）。

## 2. 构图

组件的用法：调 skill `steps`（Claude Code 用 Skill 工具调 `excalidrawer:steps`；其他宿主读 `../steps/SKILL.md`），看它的『组件』。这一步只读这一节，再读下面用到的那几份参考：axis（图表坐标轴一节写了两条轴、柱子、折线、网格怎么画）、形状与文字（垫在形状下面的线的写法在里面）、legend、semantics。不需要 stack、panel、连线。

没有专门的图表组件：数值轴和类别（时间）轴各是一条 axis，柱子、折线、圆点、网格线都用这两条轴给出的刻度和数值换算自己画。

### 柱状：类别沿横轴，柱子从零往上长

```text
 $M
 40 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
 30 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ ▇ 27.5
 20 ┄┄┄┄┄ ▇ ┄ ▇ ┄┄┄┄ ▇ ┄ ▇
 10 ┄┄ ▇ ┄ ▇ ┄ ▇ ┄ ▇ ┄ ▇
  0 ━━━━━━━━━━━━━━━━━━━━━━━
        Q1    Q2    Q3    Q4
```

- 数值轴向上，下限是 0：柱子的高度必须和数值成正比，所以柱状图的数值轴永远从 0 开始，不为了"看清差别"截掉下面一段。想看细微的变化，那是折线图的活。
- 每根柱子的底边就是基线，柱顶写数值。柱顶的数值用同一套换算算出来，不另外手写位置。
- **多系列**：同一个类别的几根柱子并排紧贴，整组居中在类别的下方；系列用不同的颜色（蓝、橙、紫的顺序），最多 3 个，配 legend。
- **类别没有天然顺序**（渠道、城市、产品）时，按数值从大到小排，读者一眼看出排名；多系列时，按同一类别各系列数值的合计排，不单看某一个系列。类别是时间或有固定次序（Q1 到 Q4、周一到周日）时，按它本来的顺序。
- **横过来**：类别名平均超过 8 个字符，或类别超过 8 个时，类别沿竖轴往下排，柱子向右长。数值轴挪到下方，网格线变成竖的，数值写在柱子右端的外面；轴左边留出最长类别名的位置。

### 折线：时间沿横轴，数值轴从一个整齐的刻度起

```text
 90 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ ●─ 88
 70 ┄┄┄┄┄┄┄┄ ●──●╱ ┄┄┄┄
 50 ┄ ●──●──●╱ ┄┄┄┄┄┄┄┄
 30 ━━━━━━━━━━━━━━━━━━━━
      Jan Feb Mar Apr May
```

- 数值轴不强求从 0：折线看的是走势，范围取数据附近、起点落在一个整齐的刻度上（比如 30 或 40），让线占满图的大部分高度。
- 每个数据点一个小圆点，点和点之间连线；线垫在圆点下面，不从圆点上穿过去。只在最后一个点的右边写数值，中间的点不写，免得图变成一排数字。
- 最多 3 条线，不同颜色（蓝、橙、紫的顺序），线和圆点同色，配 legend。时间点超过 12 个就读不清了，换成更粗的时间粒度。
- 某个时间点没有数据，这一点不画，线在那里断开，不拿零补。

### 两种图共用的

- **刻度**：数值轴的刻度用 axis 给的整齐间隔，刻度文字放在数值轴左边。刻度不超过 7 个。
- **网格**：每个刻度（基线除外）画一条浅灰的虚线，贯穿整个绘图区，垫在柱子和折线下面；它们不能用普通连线直接画，连线总是画在形状上面，会盖住柱子。垫在下面的写法在 `steps` 的形状参考里。
- **轴标题**：可选。数值轴的标题（带单位）放在轴顶上方、靠左；类别轴的标题放在类别文字下面。
- **legend**：多系列才画，放在绘图区右上角、图的外面，样本是和系列同色的色块；单系列不画。
- **配色**：同一个系列在整张图里始终一种颜色；一张图不超过 3 个系列色，不用红色（红色读作"坏"）。轴线、刻度文字、数值文字都是默认的墨色。
- **标题**：点明这张图量的是什么、哪段时间，比如「Quarterly revenue, FY2025 vs FY2026」，不写「Chart」。

### 不做的

双纵轴、堆叠柱、百分比堆叠、饼图和环形图、面积图、图里的交互：这一种图都不做。用户要的是这些时，直说做不了，给最近的替代：双纵轴拆成上下两张共用横轴的图，堆叠柱改成并排柱，饼图改成按大小排好的横向柱状。

## 3. 出图

出图、命名、导出格式、两层质量关、迭代：调 skill `steps`（Claude Code 用 Skill 工具调 `excalidrawer:steps`；其他宿主读 `../steps/SKILL.md`），看它的『出图』。这一步只读这一节。图表的文件名用 chart-<name>。

质量关里多看一件事：用图上的刻度和网格线当尺子，量一下柱顶、末点的位置和旁边写的数值对不对得上，对不上就是换算用错了。

## 4. 常见画坏法

| 画坏了长什么样 | 为什么 | 回到哪一步改 |
|---|---|---|
| 柱子从图的顶上倒挂下来，或者数值大的反而短 | 数值轴用了向下的方向，零在上、大值在下 | 构图：axis，数值轴用向上的方向 |
| 柱顶的数值和柱子的高度对不上 | 柱子和数值各算各的，没有走同一个换算 | 构图：axis，柱高、柱顶位置都用数值轴给的换算 |
| 柱状图的柱子都差不多高，看不出差别，或差别被夸大 | 数值轴没从 0 开始 | 构图：柱状图数值轴从 0 起；要看细微变化改用折线 |
| 网格线盖在柱子或圆点上，柱子上有一道道虚线 | 网格线用了普通连线，它总画在形状上面 | 构图：网格线垫在下面，写法见形状参考 |
| 折线从圆点中间穿过，点像被串起来 | 折线也用了普通连线 | 构图：折线垫在圆点下面 |
| 刻度是 37、74、111 这样的怪数 | 数值轴的范围随手取了，没落在整齐的刻度上 | 构图：axis，范围的两端取整齐的数 |
| 类别名挤在一起或折成几行 | 类别名长或类别多，还画成竖柱 | 构图：类别平均超过 8 个字符或超过 8 个，改横着的柱状 |
| 柱顶数值互相挤在一起或压到邻居 | 多系列的柱子太窄 | 构图：减少系列，或类别多时改横着的柱状 |
| 末点的数值被画布右边缘切掉 | 折线最后一点右边没留写数值的位置 | 构图：绘图区右边留够位置 |
| 多条线或多组柱分不清谁是谁 | 没配 legend，或两个系列颜色太接近 | 构图：legend，系列色用蓝、橙、紫 |
| 超过三个系列，图成了一团 | 一张图装了太多 | 问清楚：留哪三个，或拆成两张 |
| 出图后质量关有警告，或看图有一条不过 | 前面某一步的几何没改对 | 出图：按警告和自检的结论改，回到对应的构图那一项 |
